# Restaurant seed images

Place images here for seeding restaurants or for API tests.

- **cover_sample.png** – minimal 1×1 PNG used as cover image in tests
- **gallery_sample.png** – used as gallery image in tests
- **menu_sample.png** – used as menu image/PDF substitute in tests
- **laungprabang.jpg**, **patuxai.jpg**, **thatlaung.jpg** – optional real images for manual testing or seeding

Tests in `tests/test_restaurants_api.py` use files from this directory when available.
